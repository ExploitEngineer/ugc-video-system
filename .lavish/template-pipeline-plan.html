Make the template pipeline truly separate

The template pipeline is supposed to be fully driven by the picked template. Today it piggybacks on the normal pipeline's ad-type detector, 2×2 storyboard, and Seedance prompts. That coupling bakes text/UI into the footage, the first "analysis" step never actually looks at the template, and every clip is force-cropped to 15s.

The concrete bug this fixes

now

Text & graphics baked INTO the footage

A "service" template makes Seedance render app-UI screens, stat cards and a brand end-card straight into the clip. Then Nexrender composites the template's OWN text on top → garbled overlap.

target

Plain footage; template owns overlays

The generated clip is plain live action. Every headline, logo, stat and end-card comes from the template's After Effects layers at composite time. If the template has an image slot, we generate an image for it - matching your ad's content and the template's look - and drop it into that slot ("still" just means a static image, not a video).

  • • footage carries no text / UI / logos / end-cards
  • • template layers render all graphics
  • • clip length = the template's real length

Duration = the template's real length revised

Templates are limited to 8-15s at upload (reject shorter/longer). The clip follows the template: masterClipSeconds(tpl) = snapUp(min(templateDuration, 15)), threaded through plan → beats → slices → video. Seedance only renders {4,5,6,8,10,12,15}s, so we generate the nearest supported length ≥ the template and After Effects trims the surplus (your "crop a second" idea, done at composite - e.g. a 9s template → 10s clip, AE keeps 9s). The number of beats/scenes scales with the template's own video slots, so a longer template gets more.
